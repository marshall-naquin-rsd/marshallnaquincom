The container for every listing, document row and panel on an Area 7 page.

```jsx
<Card tone="milestone">
  <h3 className="section-heading">Baton Rouge Area</h3>
  <p>Nine weekly meetings and a 24-hour hotline.</p>
</Card>
```

`tone="milestone"` (brass top rule) marks a confirmed intergroup.
`tone="sage"` is for the "everywhere else" / advisory panel. Default is the
record card used for meetings, minutes and literature rows.
