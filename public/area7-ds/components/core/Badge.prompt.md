A short label for a state, a service position, or a clean-time milestone.

```jsx
<Badge variant="officer">Area Secretary</Badge>
<Badge variant="gsr">GSR</Badge>
<Badge variant="milestone">5 years</Badge>
<Badge variant="info">Open meeting</Badge>
```

`milestone` is the only rounded-pill badge and the only place brass appears.
Never put a member's name next to a milestone badge — the fellowship is anonymous.
